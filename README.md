# Zepto Inventory Insights – SQL Project

## Overview
This project analyzes a retail inventory dataset using MySQL.  
It includes data exploration, data cleaning, analytical queries, and window functions.

## Tools Used
- MySQL
- SQL Queries
- Window Functions

## Key Concepts
- Data Cleaning
- Aggregations
- CASE Statements
- Window Functions

## Dataset
Retail grocery inventory dataset containing product, pricing, and stock details.

## Outcome
Gained practical experience in SQL querying, data validation, and analytical thinking.
